ML-Driven Stock Trend Prediction
Model (Nifty 50)

Built a machine learning model using LSTM (Long Short-Term Memory) neural networks to predict Nifty 50 directional trends. Achieved 78% directional accuracy over a 3-month out-of-sample backtesting window, outperforming a simple moving average strategy by 12 percentage points.

📅 Duration: 12 Weeks (2023)
👤 Role: Quant Analyst & ML Developer
🏢 Client: Personal Research + Institutional Use
🛠️ Tools: Python, TensorFlow, Pandas, NumPy

🎯 Project Overview

Equity markets are noisy, complex, and influenced by hundreds of variables. This project explored whether machine learning — specifically LSTM networks which excel at sequential time-series data — could learn patterns in Nifty 50 price and volume data to predict the direction of the next 5-day move with actionable accuracy.

The model was trained on 10 years of daily OHLCV data, enriched with 18 technical indicators and macro sentiment features. The output is a daily BUY / HOLD / SELL signal for the Nifty 50 index.

💡 Key Result: 78% directional accuracy on 3-month out-of-sample test. Simulated portfolio using model signals generated +34.2% over the test period vs Nifty's +18.6%. Sharpe Ratio: 2.1.

🏗️ Model Architecture

The model used a stacked LSTM architecture with dropout regularization:

# LSTM Model Architecture (TensorFlow/Keras) from tensorflow.keras.models import Sequential from tensorflow.keras.layers import LSTM, Dense, Dropout, BatchNormalization model = Sequential([ LSTM(128, return_sequences=True, input_shape=(60, 23)), BatchNormalization(), Dropout(0.3), LSTM(64, return_sequences=True), Dropout(0.2), LSTM(32, return_sequences=False), Dropout(0.2), Dense(16, activation='relu'), Dense(3, activation='softmax') # BUY / HOLD / SELL ]) # Lookback window: 60 days | Features: 23 | Output: 3-class # Optimizer: Adam (lr=0.001) | Loss: categorical_crossentropy

🔬 Training & Validation Setup

  • Training Data: Jan 2013 – Dec 2021 (9 years of daily data, ~2,250 trading days)
  • Validation Set: Jan 2022 – Sep 2022 (9 months for hyperparameter tuning)
  • Test Set (Out-of-Sample): Oct 2022 – Dec 2022 (3 months, strictly unseen data)
  • Class Labels: +1.5% or more in 5 days = BUY, -1.5% or more = SELL, else HOLD
  • Class Imbalance Handling: SMOTE oversampling of minority classes (SELL periods)
  • Walk-Forward Validation: Used to simulate live trading conditions and prevent data leakage

⚠️ Limitations & Risks

📌 Important Disclaimer: This model is a research tool, not a live trading system. Past backtested performance does not guarantee future results. Markets can change regime, causing model degradation.

  • Model accuracy degrades during sudden macro events (e.g., geopolitical shocks, RBI surprise decisions)
  • Transaction costs and slippage not fully accounted for in backtest simulations
  • Model requires periodic retraining (recommended: quarterly) to avoid concept drift
  • This is a directional signal model only — not a position sizing or risk management tool
